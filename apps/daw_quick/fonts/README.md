# Bundled fonts

The shell and every device panel set Inter for words and JetBrains Mono for
numbers. Both ship here, so the panels look as designed on any system and
Canvas text (which, unlike Text items, warns rather than falling back) always
finds its family. `register_bundled_fonts()` adds them at startup.

- Inter-*.ttf (Light to ExtraBold): Inter 4.1 by Rasmus Andersson, SIL Open Font License 1.1 (Inter-OFL.txt).
- JetBrainsMono-Variable.ttf: JetBrains Mono 2.304, SIL Open Font License 1.1 (JetBrainsMono-OFL.txt).
