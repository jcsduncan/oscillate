How it works: the same steps every time
1 RENDERSong and every trackOffline, with the export engine, while you keep working. Nothing plays.
2 MEASURESix checksSub rumble, mono safety, resonances, kick/bass cancellation, band balance, level and crest.
3 BLAMEWhich trackA problem in the mix is traced to the track renders that contain it.
4 FIXOne rule, one deviceRumble → Contour high-pass. Width → Vista band. Ringing → Temper cuts. Clash → Lock.
5 RE-CHECKProofRenders again: the target moved, nothing else did by more than 0.1 dB.
