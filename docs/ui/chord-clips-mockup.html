Chord Clips

Chords are MIDI notes in a clip, the clip you already edit. The chord strip above the piano roll reads the chords from the notes. Move a note and the name follows; pick a new chord in the strip and its notes are re-voiced in the same rhythm. Write fills the clip from a mood and a shape, Chord changes what's selected, Rhythm turns held chords into a part. Every step is one undo.
