Everything soothe3 does

  • Depth and Detail (soothe3 merged sharpness and selectivity into this one control; high Detail goes after narrow ringing).
  • Soft mode with an adaptive threshold, and Hard mode for more bite.
  • Tilt leans Detail, Attack and Release toward the lows or highs. Max Cut caps how deep any cut can go.
  • Low latency for tracking, Natural (minimum phase) and Linear phase for parallel and mid/side work.
  • A drawn sensitivity curve sets where it listens, and Delta lets you hear only what is removed.

What Temper adds

  • Dynamic EQ bands on the same display: up to 8 bells, shelves and cuts, each with threshold, ratio and range. Use them for the problems you can name, and leave the rest to the suppressor.
  • Unmask: a sidechain that carves only the frequencies the other track needs, only while it plays (the bass makes room for the kick at 50–110 Hz and nowhere else).
  • Split: separate depth for attacks and sustains. It tames ringing tails without dulling the hits.
  • A reduction heatmap, so you can see which notes and syllables set it off.

How it will be built

  • A new native effect on the existing platform, which already has sidechain inputs and reported latency.
  • An STFT engine with overlap-add, plus a minimum-phase path that resynthesises per-bin gains as a smooth filter. Low latency uses short frames.
  • Oracle tests: a sine buried in noise is cut and the noise is left alone; a static tone stays unchanged at Depth 0; Delta plus Out equals In exactly; export matches live playback; latency is as reported.
  • Then presets for vocals, guitars, cymbals, mix bus, bass unmask and de-essing, then the panel.
