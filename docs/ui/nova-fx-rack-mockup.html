Nova FX rack

The chain on the left reads top to bottom, in the order the sound passes through it. Drag any row to reorder it, drop it on a bus to move it, or click a row to jump to that module. Every module is shown full width on the right, with all of its controls.

Order and routing

  • Drag the whole row, not a tiny handle. An amber line shows where it will land, and the sound changes on release as one undo step.
  • Drop a row on BUS 1 or BUS 2 to move the module there. Hold Ctrl while dropping to copy it instead.
  • Each row has a small in/out meter, so you can see which module is adding level and which is taking it away.
  • The bus tabs show their send, their return and a live meter, and the split and oversampling settings sit at the foot of the rack.

Modules

  • Every control is visible. The MORE button is gone.
  • Click a module's name to swap it for another, from a browser grouped by type with a one-line description of each.
  • Each module type gets 4–6 presets (◂ ▸ to step through them), plus Save as… for your own.
  • The ⋯ menu offers Duplicate, Move to bus, Copy and paste settings, Reset and Remove. You can also collapse a module to a one-line summary.

Live displays (engine work)

  • The engine sends more telemetry: each slot's input and output level and its gain reduction, a per-band gain reduction for Multiband, and a 64-band spectrum after the selected module.
  • Filter and EQ: drag the nodes on the curve, with the real spectrum behind it.
  • Compressor: a moving dot on the transfer curve and a gain-reduction meter.
  • Delay: the taps drawn on the beat grid, with ping-pong shown on separate L and R lanes.
  • Reverb: pre-delay and the decay curve drawn in seconds.
