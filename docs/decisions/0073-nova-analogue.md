# ADR-0073 — Nova Analogue: seeded voice cards, drift and Voice Lanes

**Status:** Accepted; implemented. **Date:** 30 October 2026.
**Builds on:** ADR-0057 (Nova and its structured document), ADR-0066 (Ember's circuit model and its seeded per-voice tolerances), ADR-0072 (`SynthKernel::locate`).
**Contract:** `include/oscillate/native_dsp/synth/nova/analogue.hpp` (lanes, limits, `analogue_lane_values`, the edit helpers), `project::NativeVoiceLane` / `NativeVoiceValue` and `NativeSynthDocument::voice_lanes` in `include/oscillate/project/model.hpp`, spec 08a §2.12b (parameters), §3.7 (document) and §4 (sources). Design: `docs/ui/nova-analogue-mockup.html`.

## Context

A polysynth built from analogue voice cards never plays two voices alike: each card is a little sharp or flat, brighter or darker, slower to open, louder, and everything wanders as it warms. That is a large part of why chords on old polysynths sound alive and digital ones sound sterile. Nova had a per-oscillator drift and random start phases, but every voice was otherwise the same. The user makes minimal techno and house and wants warm, moving parts; the mockup ("Age", tolerances, Voice Lanes, voice cards) was approved.

## Decision

1. **Fixed offsets per voice, from a seed.** `nova.analogue.seed` (1..9999) and a voice's number give every part a value `u` uniform in −1..1 (`analogue_seeded`, a 64-bit mix of seed, kind, oscillator, part and voice). Note voices are numbered by the allocator's slot (0..39: 32 playing plus stolen voices' fades); unison voices by their place in an oscillator's stack (0..15). A voice keeps its character from note to note and from render to render; New synth (a new seed) rolls a new set.
2. **Tolerances and Age.** The offset a voice plays is `clamp(u × tolerance × Age × 1.6, −1, 1)` times the part's maximum: pitch ±12 cents, cutoff ×1.18^±1 (symmetric in octaves), resonance ×(1 ± 0.10), envelope times ×1.25^±1 (attack, hold, decay, release of all four), level ±1.5 dB, pan ±40 % (a note voice's balance; added to a unison voice's pan), oscillator shape ±8 % (pulse width, position and warp amounts). The headroom 1.6 (`analogue_age_headroom`) makes Age 1 at full tolerance land most voices near the maximum, the widest pinned to it, as worn trimmers are. Age 0 removes every offset.
3. **Voice Lanes.** Pitch, Cutoff, Env, Level, Pan, Phase, Mod A and Mod B are lanes the user can paint per voice. A painted value replaces the seeded one for that voice and survives Age and seed changes. Unison voices share their note's filter, envelopes and matrix, so only Pitch, Level, Pan and Phase reach them; the others are rejected for the unison kind. Phase offsets the start phase by up to ±180° (with Age, tolerance 1). Mod A and Mod B are not scaled by Age: they are values for the matrix and the route's amount scales them.
4. **Drift.** Each voice wanders on two incommensurate sines (ratio 1.37, weights 0.6 and 0.4, seeded phases) on its own drift clock, so the wander is smooth, band-limited and bounded by ±Amount × 8 cents; On Cutoff moves the cutoff by up to ×1.10^±1. Rate maps 0..1 to 0.02..0.62 Hz and each voice's clock runs up to 25 % faster or slower. The clock starts at `rate × (the note's project frame / rate)`, as if the voice had wandered since the project's start, and then integrates the rate tick by tick, so automating Rate glides instead of jumping. Drift does not scale with Age.
5. **Free-running oscillators.** With Free-running on (default), a new note's oscillators start where they would be had they run since the project's start (`frac(hz × frame / rate)` plus a seeded offset per note voice and unison voice) instead of at the reset phase: notes start mid-cycle, as on a VCO synth. This is the one thing Age 0 keeps; turn Free-running off for reset starts.
6. **Scope.** "Notes + unison", "Notes only" or "Unison only" chooses which kinds get offsets and drift. Free-running phase applies to every oscillator whichever the scope.
7. **Determinism.** Every offset is a pure function of the seed, the voice's number and the note's project frame (`SynthKernel::locate` gives the kernel the frame of every note), and the drift clock advances by whole control ticks, whose boundaries are fixed in project frames. An export therefore matches playback, and any host block split renders the same samples. Seeded units are drawn when a note starts (control-rate work, no allocation); each tick only scales them.
8. **Off is exact.** With `nova.analogue.on` Off no offset, pan or drift is applied and the oscillator gets no per-unison data, so the rendering is the same as before Analogue existed; Age 0 with drift and Free-running off is also exact (tested). Mod A, Mod B and Spread are sources whether or not Analogue is on.
9. **New modulation sources.** `voice.mod_a` and `voice.mod_b` are each note voice's Mod A and Mod B lane values mapped to 0..1; `voice.spread` is 0.5 for a note voice (Nova's matrix runs per note voice, so a unison voice's place in its stack is not yet a source). Appended after `bend`, so saved routes keep their sources.
10. **Unison curves.** "Inverse" (`sign(x)·√|x|`, the mirror of Exponential: inner voices spread out, outer ones less than linear would put them) and "Random" (each voice at a seeded distance on its own side of the centre, fixed per stack size) are appended to `nova.osc.<o>.unison.curve`.
11. **Document.** Painted values are a new optional section of the structured document, `voice_lanes`: `NativeVoiceLane{id, values[{voice, value}]}` with ids `notes.<lane>` and `unison.<a|b|c>.<lane>`. The project checks structure (unique ids, at most 64 lanes of 64 values, voices strictly increasing, values finite in −1..1); Nova checks meaning (known lane, kind, voice range). The codec writes the section only when it has lanes, like regions, so schema 1.44 files load unchanged and the schema version is not raised. The panel reads lanes through `analogue_lane_values`, the kernel's own code, and edits them through `set_analogue_lane_value` / `clear_analogue_lane` on the document model, so a paint stroke between `begin_edit` and `commit_edit` is one undo step.

## Consequences

- 15 parameters (`nova.analogue.*`) are appended after Kick Lock: 1129 in all. Telemetry grows to 2035 floats (08a §6).
- Five factory presets use Analogue (Detroit Chord Stab, Warehouse Poly Pad, Worn Unison Lead, Dub Chord Echo, Old Card Brass), appended so earlier preset indices are unchanged.
- Engines whose documents hold no voice lanes (Anvil, Pump, Crate) reject them.
- Rejected: a JSON blob in the document (unchecked by the project, unlike every other section); drift as a pure function of project time (a Rate change would jump the wander anywhere in its range); recomputing seeded values every tick (hundreds of hashes per voice per tick for unison stacks).

## Voice cards, re-roll, flutter, noise AM (2026-10-30)

A common analogue-warmth recipe used with wavetable synths is: a fixed number of voices whose per-voice values are partly fixed and partly re-rolled each note, an almost inaudible fast pitch flutter from low-passed noise, and a noise layer whose level follows oscillator A. Four additions cover it; each defaults to off, so every earlier patch and preset renders bit-identically (tested).

1. **Voice cards** (`nova.analogue.cards`, 0..16). 0 keeps numbering note voices by allocator slot. N ≥ 1 gives the synth N cards: each note that takes a fresh voice takes card `n mod N`, and its seeded offsets, painted `notes.*` lane values (voice = card), drift and free-running identity and Mod A/B are the card's, not the slot's. **Card rule:** `n` counts notes that took a fresh voice since the kernel's last `reset()`. The runtime resets the kernel whenever the transport generation it is given changes (a seek, play from a position, an export start, and a loop jump when it starts a new generation), as it resets every other note state, so a render from a given position always deals the same cards and export matches playback from the same start. Mono and legato retriggers keep their voice's card. Two notes may hold one card at once (more notes than cards); they then share its offsets, as no real 6-voice synth could. The lanes show N bars; telemetry's eight card slots (§6) report by card.
2. **Re-roll** (`nova.analogue.reroll`, 0..1). At each note every part's value (painted or seeded) gets `reroll × u′` added, scaled as the seeded part is (tolerance × Age × 1.6; Mod A and Mod B unscaled) and clamped to −1..1, with `u′` drawn from the seed, the voice (card, or place in the unison stack) and the note's number `n`. Successive notes on one card differ; a render repeats. Like Serum's RANDOM column.
3. **Flutter** (`nova.analogue.flutter.amount` 0..1 → ±15 cents, `flutter.tone` 2..60 Hz log, default 12). Each note voice and unison voice (per scope) has its own generator: a 64-bit LCG seeded from the seed, the voice and the note's project frame, one draw per control tick through a one-pole low-pass at Tone, normalised to a spread of 0.35 and clamped to ±1. Control ticks sit on fixed project frames, so any block split draws the same sequence; the increment ramp between ticks smooths it. It starts from rest (in tune) and does not scale with Age.
4. **Noise AM** (`nova.noise.am.source` [Off, Osc A, B, C], `amount`, `curve`). Per sample at the internal rate, the noise is multiplied by `1 − amount + amount × u^(2^(2 × curve))`, `u` the followed oscillator's signal before its level mapped to 0..1. Curve below zero is smoother, above zero buzzier (08a §2.12c). It works whether or not Analogue is on. The cross-modulation value the noise publishes stays the raw noise.

Consequences: 7 parameters appended (`nova.analogue.cards`, `reroll`, `flutter.amount`, `flutter.tone`, then `nova.noise.am.*`): 1136 in all. Telemetry is unchanged in size. Re-roll draws twice the seeded units at a note's start (control-rate, no allocation); flutter costs one draw and one filter step per sounding voice per tick, only while its amount is above zero. Rejected: deriving the card from the project position (the kernel does not see notes before the transport position, so it could not count them); flutter as a pure function of project time (a Tone change would jump it).

## Addendum 2026-10-31: glide tolerance and synced portamento

- `nova.analogue.glide` adds a seeded per-voice portamento time scale
  (±35 % at full tolerance and Age, before headroom), so voice cards slide
  at slightly different speeds. It is a new part appended after the
  existing ones, so every existing seeded offset is unchanged.
- `nova.global.portamento_sync` / `portamento_division` give the glide in
  note values of the project tempo (default 1/32), so a sequenced slide
  lands on the grid and keeps its feel when the tempo changes. Seconds stay
  for short, feel-set and 303-style glides. 1139 parameters.
