# Combined Quick, VST3 scanner and codec dependency audit

**Status:** Local engineering evidence, 15 October 2026. **Not a release or legal sign-off.** This audit is for a fresh Ubuntu 26.04 x86-64 prototype at repository commit `1b6a8e6`. It combines the Qt Quick UI, VST3 scanner/helper, libsndfile codec adapter and export resampler in **one** `BUILD_TESTING=OFF` build. Earlier [package prototypes](ubuntu-package-prototype.md) tested the scanner and codec switches separately. No AppImage was built.

## Exact observed artifact and build

The local build used GCC 15.2.0, CMake 4.2.3, Ninja 1.13.2 and Python 3.14.4. CMake selected Qt 6.10.2, PipeWire 1.6.2, OpenSSL 3.5.5, nlohmann/json 3.11.3, VST3 SDK `v3.8.1_build_84`, Ubuntu libsndfile 1.2.2-4 and libsamplerate 0.2.2-4build2. The cache had `BUILD_TESTING=OFF`, `OSCILLATE_BUILD_QUICK_UI=ON`, `OSCILLATE_BUILD_VST3_SCANNER=ON`, `OSCILLATE_BUILD_CODEC_ADAPTER=ON`, `OSCILLATE_BUILD_EXPORT_RESAMPLER=ON`; legacy Widgets UI, source resampler and convolution DSP were off. JACK headers were not found. These are observed build inputs, not a release lockfile.

The local `.deb` is `oscillate-quick-prototype_0.1.0~prototype1_amd64.deb`, SHA-256 `23e9c8c7888eeefb58360bd89beb34f20046c642bda798d8791efbc49245c21d`. `dpkg-deb --contents` found exactly:

Neither executable has an ELF `RPATH`/`RUNPATH`. `readelf -d` shows the scanner helper directly needs only `libstdc++`, `libgcc_s` and `libc`; SDK code is compiled into project binaries rather than linked as an SDK `.so`. The Quick ELF directly needs Qt Core, Gui, Qml, Quick and Widgets, PipeWire, OpenSSL Crypto, libsamplerate, libsndfile and the C++/C runtimes. It does **not** directly need Qt Test or JACK. The prototype's `dpkg-shlibdeps` `Depends` lists the corresponding Ubuntu packages, with minimum ABI versions, not the exact local versions below. The extracted Quick executable created and reopened an offscreen smoke project; that does not qualify X11, Wayland, plugin compatibility or a clean-host install.

## Stretch/pitch path: planned input, absent from this package

[Signalsmith Stretch 1.4.0](https://github.com/Signalsmith-Audio/signalsmith-stretch/tree/1.4.0) at `a670068d9aeb64913331d5cc29337b19a457a7df` and its [Signalsmith Linear 0.6.4](https://github.com/Signalsmith-Audio/linear/tree/0.6.4) dependency at `de55e6a50ffcf6f8f43f649692d94691c7025151` are **prototype-only**, not CMake production targets or package payload. Their checked local `LICENSE.txt` files are both MIT (SHA-256 `ee2ef82481ffb445ecdd4b3a4c1f82c0cddb2da8fe39d8e8dc384fffb3e7f06f` and `072b5e9eb5b22880bdf6256324654cf3ce53dba828edb911921121e1be09d9c3`). Upstream confirms [Stretch's MIT terms and Linear dependency](https://github.com/Signalsmith-Audio/signalsmith-stretch) and [Linear's MIT terms](https://github.com/Signalsmith-Audio/linear). If adopted, freeze both exact header trees and include both notices in binary/source distributions. The prototype adapter has since been removed; warp uses the project's own engines (ADR-0026). Alternative [Rubber Band](https://breakfastquay.com/rubberband/license.html) is GPL-2.0-or-later or commercially licensed, while [SoundTouch](https://surina.net/soundtouch/license.html) is LGPL-2.1; neither is linked or approved for this package. Switching to either requires a fresh product-licence and package assessment.

## Unresolved release decisions and replay

1. Select and publish the project's code licence and starter-sound grant. Add a package copyright file and third-party MIT notices for SDK/nlohmann code compiled into binaries. The current prototype's warning file does not satisfy that inventory.
2. Record a single reproducible release feature preset and build-input hashes. The observed `.deb` has both scanner and codec, but no JACK, source resampler or convolution core. Re-run tests for codec formats, VST3 effects/instruments, device backends and export on the chosen artifact.
3. Resolve LAME's file-level licence issue and decide how Qt/LGPL source, licence text, shared-library replacement and notice routes will be delivered for a native package. Record review against the exact artifact hash; do not infer completion from a `Depends` field.
4. Build a separate AppImage, then enumerate **every copied file**, Qt QML/platform plugin and type-2 runtime component with exact version, hash, licence, notice and source/replacement route. This `.deb` inventory does not describe that future payload. Test on clean Wayland and X11 Ubuntu 26.04 targets.

Replay this observation with the options above, `cmake --build build/audit-quick-scanner-codec --target oscillate oscillate_vst3_scan_helper -j1`, then `python3 scripts/package-ubuntu-prototype.py --binary build/audit-quick-scanner-codec/apps/daw_quick/oscillate --scanner-helper build/audit-quick-scanner-codec/apps/daw_quick/oscillate_vst3_scan_helper --output-dir build/audit-package`. Inspect `dpkg-deb --field`, `dpkg-deb --contents`, `readelf -d` for both binaries and the generated `.inventory.json` before relying on any result. The ignored local build and package are evidence only; neither is committed or approved for publishing.
