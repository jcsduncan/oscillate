# Tests

Module tests live under `tests/<module>/` and are registered with CTest by their module-local CMake target. The foundation contract tests exercise stable ID parsing, structured results and bounded diagnostic payloads. Timeline tests cover tempo ramps, meter boundaries, conversion rounding and validation. Project tests cover atomic revisions, mixed-anchor intervals, source-frame ranges, undo/redo and transport-gated rate changes. Engine tests cover processor continuity and block-boundary graph publication. Later test suites must use the acceptance evidence in the functional specs and keep failure paths and high-risk branches covered.

The default local coverage preset builds Qt Quick and runs its integration tests, then measures the reusable `src/` and `include/` modules. App workflows therefore contribute execution evidence for their core code paths; Qt Quick C++ is measured separately by `coverage-full`. The gate excludes `src/audio_io/pipewire_output.cpp` because its PipeWire callbacks and server lifecycle need a running audio server. The optional JACK adapter is included when its development package is available; the uncovered `jack_*` forwarding wrappers need a live-server qualification run rather than fake callbacks. The measured modules remain subject to the 90% aggregate gate. For separate device evidence, configure with `-DOSCILLATE_AUDIO_IO_LIVE_TESTS=ON` and run `audio_io_pipewire_live` against a local PipeWire server at 64 and 128 frames. This smoke does not replace physical disconnect, xrun or reference-hardware qualification.

`coverage-full` enables Qt Quick, VST3, codec, convolution and both resampler options. `./scripts/check-coverage.sh coverage-full` adds `apps/daw_quick/` to the measured C++ sources and reports per-file and aggregate coverage. This is a diagnostic report while the optional targets are brought under the 90% floor; it is not a passing full-product coverage gate yet. The [full coverage baseline](../docs/quality/full-coverage-baseline.md) records the measured gap and next test work. QML has no gcov line coverage and instead needs UI contract and workflow tests. Configure the full preset with the pinned VST3 SDK root in an ignored `CMakeUserPresets.json` or with `-DOSCILLATE_VST3_SDK_ROOT=...`; PFFFT is vendored. The default core gate remains mandatory and must not be described as coverage of the whole app.

The Qt Quick transport smoke runs under GCC, Clang and ASan/UBSan. An instrumented Qt Quick ThreadSanitizer attempt on 14 October 2026 reported five races and a thread leak entirely in the installed, uninstrumented Qt Core/Qml/DBus libraries during QML startup/shutdown; the smoke failed for those reports, with no project-source stack in the reports. Headless TSan covers the application and audio-worker contracts separately. A narrow bridge-only concurrent fixture or a TSan-compatible Qt build is still needed to qualify the Quick worker handoff itself; no suppression is applied to the regular smoke.
